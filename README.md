# 水準測量現場紀錄 V0.3.0

試用網址：<https://oxsum324.github.io/level-survey-recorder/>。Windows 也可雙擊原工具箱根目錄的 `啟動水準測量紀錄.bat` 在本機使用。第一次在線開啟後，工具程式可離線使用。案件資料與照片存在目前瀏覽器的 IndexedDB，不自動上傳；離開現場前請匯出完整案件 JSON，並在目標資料夾核對。不同裝置、瀏覽器或網址的資料不會自動同步，換裝置時請匯出並匯入案件檔。

## 現場流程

1. 建立案件、BM 點，選起點／預定終點。回測同一 BM 就選同一點；不同終點須填兩個已知高程，並註明高程基準與來源。
2. 輸入人工指定容許閉合差（±mm），選按測站數等分或按各站長度比例分配改正數。未指定容許值時不判定合格，也不產生改正後高程。
3. 填約略地址或路名，從工具開啟 Google 地圖搜尋並選擇作業範圍；截圖後可在工具頁按 Ctrl+V、按「貼入剪貼簿圖片」，或從檔案匯入位置圖。填寫底圖來源與截圖日期，再建立 BM、S、TP 點逐點加註。底圖只用於定位示意；距離分配使用手動輸入的各站測線長度。
4. 第一站於 BM1 輸入後視。每個下一點選「中間視 IS」或「前視 FS」；搬站後同一點的後視 BS 會顯示在前視同一列。S 點可依現場實際操作作中間視，或作換站點。附件例中 S1～S3 是中間視，S4 與 TP 各有前視及下一站後視。
5. 最後前視點等於預定終點時，工具比較實測終點高程與已知高程。閉合差未超出人工輸入容許值時，才顯示簡易改正後高程；超限保留原始讀數並停止改正。
6. 點位照片須選對應點位；設備照片另存於「設備照片」區，可記錄儀器編號與位置說明。新案件預設儀器為 PENTAX AP-128，可自行修改。公司提供之 PENTAX AP-128 原始照片作為型號參考照，與本案當日拍攝照片分開標示；列印／另存 PDF 亦明確區分。完整 JSON 保留可編輯案件與本案圖像原檔。

## 計算邊界

- 單一測線的逐站高程為 `儀器視線高 = 起點高程 + 後視`、`下一點高程 = 儀器視線高 - 前視／中間視`。
- 閉合差為實測終點高程減終點已知高程；中間視不計入後視、前視合計。
- 改正數為閉合差反號，按站數等分或按人工輸入各站測線長度比例分配。中間視高程承接所在測站起點的累計改正；不以位置圖或照片推定工程距離。
- 這是單一測線的簡易閉合差分配，不涵蓋往返測、系統誤差改正、網形平差、不同高程基準換算或點位穩定性判斷。容許值需依個案作業依據輸入，工具不預設合格門檻。
- 原始讀數永遠與暫算／改正後成果分列。超限、缺讀數、終點不符、距離分配缺各站長度時，不產生改正後高程。
