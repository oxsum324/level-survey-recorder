# 水準測量現場紀錄 V0.6.1

正式網址：<https://oxsum324.github.io/level-survey-recorder/?release=0.6.1>。Windows 也可雙擊原工具箱根目錄的 `啟動水準測量紀錄.bat` 在本機使用；該本機副本需另行同步。第一次在線開啟後，工具程式可離線使用。案件資料與照片存在目前瀏覽器的 IndexedDB，不自動上傳；離開現場前請匯出完整案件 JSON，並在目標資料夾核對。不同裝置、瀏覽器或網址的資料不會自動同步，換裝置時請匯出並匯入案件檔。

V0.6.1 觀測讀數頁會預選下一個未觀測點，左右鍵可逐點切換；點選目前點號可進入全螢幕搜尋清單。已觀測點仍可選作回測。新增臨時點或記錄讀數後的提示顯示在頁面內，不遮住輸入欄；記錄後也不再自動打開點位清單。測量讀法仍由現場選擇，S 或 TP 點均可作中間視或換站前視。

V0.6.0 增加螢幕常亮、強光大字、讀數超尺時手動修正、即時暫算高程及讀數操作復原。已存讀數（含三絲、測線長度、倒尺與點位選擇）更正時必須填原因，成果表與報告保留更正軌跡；首次觀測另記錄時間。照片保留 EXIF／檔案／匯入時間來源，報告增加環境與開工檢核。完整案件檔可下載或由支援的手機分享，未匯出變更有提示。報告和總表列出資料 SHA-256 指紋，可用「驗證案件檔指紋」檢查備份而不取代目前案件。

V0.5.0 新增選填三絲讀數與視距、升降法算術複核、C√K 容許值輔助、成果總表 CSV，以及儀器檢校與兩樁法紀錄。未填這些選用資料的既有案件仍可照原流程記錄。三絲的視距乘常數預填 100，須依本案儀器資料核對；三絲容許值與公式 C 值均不預設。

V0.4.4 新增案件可調整的水準尺長度（預填 5 m）、超尺讀數即時提示、倒尺勾選與帶版本參數的離線頁面快取。建立新案件或開啟案件檔前，如目前已有讀數、圖面或照片，可選先匯出、直接取代或取消。安裝至主畫面與持久儲存請求只能降低資料遭清除的機率，不能替代案件檔備份。

## 現場流程

1. 建立案件、BM 點，選起點／預定終點。新案件 BM1 預填 10.000 m，標示為假設高程，可改為實際高程與已知高程性質；不同 BM 閉合前須確認兩端同一高程基準。可填預計 S 點與另編 TP 點總數，一次建立點號；只建立點位選項，不預填觀測讀數或固定換站順序。降低預計數量不會刪除已建點位。
2. 輸入人工指定容許閉合差（±mm），選按測站數等分或按各站長度比例分配改正數。未指定容許值時不判定合格，也不產生改正後高程。
3. 填約略地址或路名，從工具開啟 Google 地圖搜尋並選擇作業範圍；截圖後可在工具頁按 Ctrl+V、按「貼入剪貼簿圖片」，或從檔案匯入位置圖。填寫底圖來源與截圖日期；BM、S、TP 點可在讀數前或讀數後標圖。底圖只用於定位示意；距離分配使用手動輸入的各站測線長度。
4. 儀器觀測者於 BM1 輸入後視。「下一點」優先列出尚未觀測的預排點，亦可按「選下一未測點」或臨時加 S／TP；已測點仍可選作回測。讀法由觀測時選「中間視 · 同站」、「前視 · 換站」或「前視 · 終點」。換站後，畫面立即在同一點要求下一站後視；完成站收進歷史區，僅展開目前站。S 點可依現場角色作中間視或轉點。
5. 攝影者在獨立頁依點號拍照、標圖；可與觀測者、扶尺人員分工。兩部裝置作業時，建議先選定共用位置圖，再由觀測者匯出攝影工作檔。攝影者載入後拍照、標圖並匯出攝影成果，觀測者合併新照片與原案件尚未填的位置／說明，不覆蓋既有讀數或標註。兩端若使用不同底圖，圖上位置不合併。新增點位後需重新交付工作檔，資料不會自動同步。
6. 計算與閉合檢核獨立成頁，手機先顯示閉合差與逐站讀數卡片，下方另有可左右滑動的「水準測量成果總表」。總表僅包含有觀測讀數的點位，未使用的預排點不列入報告圖上標記、點位清單或現場照片。總表可單獨列印／另存 PDF 作為報告附件；未完成或未檢核時會清楚標示。最後前視點等於預定終點時，比較實測終點高程與已知高程。閉合差未超出人工輸入容許值時，才顯示簡易改正後高程；超限保留原始讀數並停止改正。
7. 設備照片另存於「設備照片」區。新案件預設儀器為 PENTAX AP-128，可自行修改。公司提供之 PENTAX AP-128 原始照片作為型號參考照，與本案當日照片分開標示。完整 JSON 保留可編輯案件與圖像原檔。

### V0.5 現場選填檢核

- 每筆後視、前視或中間視可展開「上絲／下絲」。輸入後顯示中絲與上下絲平均值的差及視距。中間視不列入前後視距平衡。三絲差超出自行輸入的容許值時提示，但不阻擋主讀數計算。
- 各站在「本站已記錄」中顯示前後視距與差。兩側三絲都齊全時，可把視距和帶入本站測線長度；覆蓋原有人工長度前會確認。各站長度可供距離比例改正與 C√K 公式使用。
- 「計算與閉合檢核」另列升降法算術複核。兩法點高程差超過 0.0005 m 時標示不一致並暫停自動改正；主讀數與原始高程仍保留。
- 使用 C√K 時，自行輸入 C（mm），每站測線長度須齊全且大於零；工具以長度總和換算 km，計算值取到 0.01 mm 並帶入容許值。請同時填寫容許值依據。
- 成果總表可匯出 UTF-8 BOM CSV，供 Excel 開啟。CSV 保留逐筆 BS／IS／FS 讀數順序；未進行改正時，改正數與改正後高程保持空白。
- 設備區可選填儀器編號、校正日期與單位、兩樁法五項資料；誤差與每 100 m 換算量只顯示數值，不自動判定合格。

## 計算邊界

### V0.6 資料欄位與指紋

- 案件沿用 `schema: 1`、IndexedDB 版本 1 與 `level-survey-case.v1` 完整案件檔格式。新增 optional 欄位：`auditLog`、`environment`（天氣、氣溫、開始／結束時間與手動覆寫旗標、備註）、`checklist`、`lastModifiedAt`、`lastExportedAt`；照片新增 `capturedAt`、`capturedAtSource`。舊照片沒有原拍攝時間時，以原有 `addedAt` 標為匯入時間。
- 首次填入讀數時，測站以 `bsAt`、`fsAt`、`bsUpperAt`、`bsLowerAt`、`fsUpperAt`、`fsLowerAt`，中間視以 `at`、`upperAt`、`lowerAt` 記錄時間。後續更正不覆寫首次時間；舊案件缺少時間戳時保持空白。
- 報告資料指紋納入案件識別與名稱、日期、人員、儀器與地點、點位、測線、原始測站、操作紀錄、儀器檢校、環境、檢核、照片中繼資料及全部媒體原檔的 SHA-256。指紋以鍵名排序後的資料計算；陣列維持原順序。排除 `lastModifiedAt`、`lastExportedAt`、`updatedAt`、`appVersion`、`pointPlan`、`photoTaskMode`、`photoTargetIds` 等純同步、版本或介面欄位。指紋可確認兩份資料內容是否一致，但不能替代簽章或原始檔保管。
- 強光與螢幕常亮為本裝置偏好，存在 `localStorage`，不寫入案件或指紋。讀數破壞性操作的復原堆疊只在目前頁面記憶體保留，重新載入後清空；更正紀錄仍保留在案件中。

- 單一測線的逐站高程為 `儀器視線高 = 起點高程 + 後視`、`下一點高程 = 儀器視線高 - 前視／中間視`。
- 閉合差為實測終點高程減終點已知高程；中間視不計入後視、前視合計。
- 假設高程回測同一 BM 可計算相對閉合差；以假設高程起測、終點為另一已知 BM 時，不判定閉合合格或執行改正。
- 改正數為閉合差反號，按站數等分或按人工輸入各站測線長度比例分配。中間視高程承接所在測站起點的累計改正；不以位置圖或照片推定工程距離。
- 這是單一測線的簡易閉合差分配，不涵蓋往返測、系統誤差改正、網形平差、不同高程基準換算或點位穩定性判斷。容許值需依個案作業依據輸入，工具不預設合格門檻。
- 原始讀數永遠與暫算／改正後成果分列。超限、缺讀數、終點不符、距離分配缺各站長度時，不產生改正後高程。
