# V0.5.0 試測紀錄

日期：2026-09-29。工作分支：`codex/v0.5-measurement-workflow`；V0.5.0 功能提交 `ca1f8ab`，起點為 V0.4.4 提交 `13e10bf`。[PR #2](https://github.com/oxsum324/level-survey-recorder/pull/2) 最初以 V0.4.4 分支為比較基準。V0.4.4 另保留在 `codex/v0.4.4-field-safety`。發布前，正式 GitHub Pages 的 `main` 為 V0.4.3 提交 `2242761`；發布核對另記於下方。

## 本版內容

| 項目 | 紀錄 |
| --- | --- |
| 2-1 三絲與視距 | BS、FS、IS 可選填上、下絲；中絲差與視距即時顯示。IS 不納入前後視距平衡。K 預填 100、可逐案調整；三絲容許值空白。兩側視距齊全時可確認後帶入該站測線長度。 |
| 2-2 算術複核 | 另以升降法計算，並比較 `ΣBS−ΣFS`、`Σ升−Σ降` 與起訖高程差；點高程差逾 0.0005 m 時提示並暫停自動改正。 |
| 2-3 C√K 輔助 | C 由案件輸入，K 為所有測站長度合計換算的 km；缺長度不帶入。容許值依據可填並列於報告。 |
| 2-4 CSV | 成果總表有 UTF-8 BOM CSV，13 欄及案件資訊列；未改正時改正欄空白。 |
| 2-5 檢校 | 儀器編號、校正日期、校正單位與兩樁法讀數可選填；只列誤差量，不判定合格。 |

保留 V0.4.4 的尺長、倒尺、覆蓋保護與離線快取。案件 `schema`、資料庫版本與完整案件檔格式仍為 1；新增欄位均可選填。原始觀測讀數不會被公式輔助或自動改正覆寫。

- CSV 實際下載檔以位元組確認 BOM `EF BB BF`，依 BS／IS／FS 順序列出。單頁 A4 成果總表與兩頁完整報告列印內容均經檢查。
- V0.4.3 完整案件檔匯入成功；原有 BM1 後視 1.000 m、前視 0.500 m 保留，新增選填欄位呈空白或預設 K=100。

## 待現場確認

- PENTAX AP-128 的實際視距乘常數及加常數，應對照儀器資料；本版僅提供可調的乘常數 K，預填 100，不據此聲稱儀器規格。
- 各案三絲差容許值、閉合差公式 C 值與依據，均由案件指定；工具不自動宣稱測量成果合格。
- 多期高程比對、多案件清單、ZIP 匯出、往返測留待後續規劃，未納入本版。
