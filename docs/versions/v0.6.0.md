# V0.6.0 試測與發布紀錄

日期：2026-09-29。工作分支：`codex/v0.6-field-flow`，起點為 `main` 的 V0.5.0 提交 `bd05803`。本版由派工說明逐項研判後實作；其中 Q7 的「待使用者決定上線」已由使用者本次明確要求發布取代。

## 本版內容

| 項目 | 結果與界線 |
| --- | --- |
| F1 | 倒尺三絲改用上絲小於下絲判斷方向；視距用兩絲差絕對值。正立尺維持原判斷。 |
| F2 | V0.5.0 重複截圖於原紀錄末尾追加更正；本版重新執行瀏覽器 Offline 重載。 |
| F3 | CSV 主要數據表頭標單位；負值讀數提示包含測站、點位及讀法。 |
| A1–A2 | 觀測頁螢幕常亮可關閉，支援時返回前景重新取得；強光大字模式為本裝置偏好。 |
| A3–A4 | 超過尺長且除以 1000 合理時顯示手動修正鍵；已記錄 IS、FS 顯示未改正的暫算高程。 |
| A5 | 中間視刪除、測站刪除、前視／中間視轉換可復原；只在本頁記憶體保留最近 20 筆。 |
| B1–B2 | 完整案件檔匯出時間另記，未匯出變更持續提醒；支援 Web Share 檔案的瀏覽器可直接分享。攝影工作檔、成果與 CSV 不清除完整案件未匯出提醒。 |
| B3 | 新照片記 EXIF 原拍攝時間、檔案時間或匯入時間及來源；舊照片顯示匯入時間。 |
| C1–C2 | 讀數、三絲、距離、倒尺與點位選擇更正需填原因；原值與新值列於報告，成果表讀數劃線標註。首次讀數另記時間，舊案件不補造時間。 |
| C3 | 成果總表與整份報告印資料 SHA-256；案件檔可在記憶體驗證，媒體原檔也納入指紋。指紋比對不是數位簽章。 |
| C4、D1 | 天氣、氣溫、起訖時間、現場備註與九項開工檢核可記錄；報告只如實列狀態，不自動判定。 |

沿用 `schema: 1`、IndexedDB 版本 1、`level-survey-case.v1` 備份格式。未填的新欄位不改變原有閉合計算或原始讀數。

## 驗證

- `node --test`：V0.5.0 原有 19 項；本版 30 項全數通過，新增倒尺三絲、mm 手動修正、EXIF 容錯、讀數更正、首次時間、資料指紋及舊格式案件等測試。
- 375 × 812 px 瀏覽器：實際輸入 BM1 後視 `1417`，畫面出現「改為 1.417 m」；手動修正後，再改為 `1.400` 時出現原因對話框。S1 中間視 `0.848`，暫算高程顯示 `10.552 m（未改正）`；轉成前視後，復原回中間視。主控台無錯誤，頁面寬度 375 px。
- 單頁總表顯示九欄、原值劃線、觀測時間與 16 碼指紋；整份報告顯示環境、檢核、更正軌跡及完整 64 碼指紋。
- 離線驗證：Playwright 瀏覽器設為 Offline 後重新整理，頁面由 service worker 載入 V0.6.0，`navigator.onLine=false`，畫面有「離線：本機資料仍可使用」，本機 BM1/S1 案件保留。這是明確的離線重載截圖，並非以線上截圖代替。
- 相容性：以 V0.5.0 測試案件檔匯入，原有 BM1 回測線 2 站及點位維持；再以 V0.4.3 測試案件檔匯入，原有 BM1 測線 1 站維持，均無載入錯誤。舊讀數的首次觀測時間欄保持空白。
- 完整案件檔實際下載後，使用「驗證案件檔指紋」讀回，得到 `1eac39dafb473d65ade8e2d929689f395a79abb848fc9edd6e447edb1e1caef4`；同一案件的整份報告頁尾指紋完全相同，驗證未取代當前案件。
- A4 列印檢查：成果總表維持一頁；整份報告在測試案件中為兩頁。調整設備參考照片的列印尺寸後，檢核表、更正紀錄與完整指紋同在第二頁，沒有孤立的頁尾第三頁。

## 修改與還原

從 `codex/v0.6-field-flow` 修改，先執行 `node --test` 與手機尺寸的輸入、列印、離線重載。若需回到 V0.5.0 程式，使用該版標籤或 `bd05803`；案件資料需另以先前匯出的完整案件檔開啟，切換程式不會自動回溯本機資料。照片原檔與案件 JSON 應一併由完整案件檔保存。
