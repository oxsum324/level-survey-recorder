# V0.6.1 現場選點與提示調整

日期：2026-09-29。

## 調整

- 預排的 S／TP 點依順序帶出下一個未觀測點；全部完成後帶出測線終點 BM，並選終點前視。點位代號不決定讀法，觀測者仍可逐點選中間視或換站前視。
- 現場下一點改為左右逐點切換及全螢幕搜尋。搜尋可用點號或位置說明，並顯示未觀測與已觀測／回測點；平常記錄不需開啟長清單。
- 記錄後不再自動開啟點位選單或數字鍵盤。臨時新增點與讀數完成提示顯示在觀測頁上方的固定行，不覆蓋讀數輸入欄。臨時新增點位可稍後由攝影或標圖人員補充位置。
- 保留既有案件資料格式；切換案件時重設未提交的下一點草稿。

## 驗證

- `node --test`：30 項通過；`node --check app.js` 與 `git diff --check` 通過。
- 375 × 812 px 瀏覽器：預排 S 25 點及 TP 3 點後，第一站自動帶出 S1；搜尋 S25 可直接選點。記錄 S1 後帶出 S2；將 S2 選為換站前視後，新站後視接 S2、下一點為 S3。臨時新增 TP4 會選為下一點，讀法仍可選中間視。兩次記錄後均未再打開點位選單，提示在頁面內顯示。
- 320 × 700 px 瀏覽器：搜尋視窗填滿手機畫面，返回觀測頁後無水平溢出。
- BM1 回測小測線：S1 記錄後帶出 BM1 並選終點前視；已觀測點仍可在搜尋視窗中選作回測。

本版未變更觀測計算、閉合差或平差方法。
