# V0.6.2 成果預覽與 PDF 輸出

日期：2026-09-29。

## 調整

- 成果總表與整份報告皆先建立可檢視的 A4 預覽，再由預覽頁選直接下載 PDF 或系統列印／另存 PDF。手機可全頁檢視，也可放大後左右滑動核對。
- 原按鈕在計算指紋及載入照片等非同步工作後才呼叫列印，部分瀏覽器可能不再將其視為直接點擊。改成預覽準備完成後，由預覽頁的按鈕同步呼叫系統列印。
- 增加離線可用的直接下載 PDF。PDF 以影像方式保存預覽排版；若需可選取文字，使用系統列印功能。
- 縮小設備參考照片的列印尺寸，避免頁尾指紋獨占最後一頁。

## 驗證

- `node --test`：30 項通過；`node --check app.js` 與 `git diff --check` 通過。
- 375 × 812 px 完整測線：總表直接下載與系統列印各 1 頁；整份報告各 2 頁。列印按鈕在直接點擊時呼叫瀏覽器列印。下載檔名包含案件編號及報表類別。
- 320 × 700 px：全頁預覽沒有頁面水平溢出；放大檢視後可在預覽區左右滑動。
- 位置圖與點位照片各匯入一張圖像的案件：整份報告的直接下載與系統列印各 3 頁，已檢查圖面、照片、成果表、檢核表及頁尾均有內容。
- 使用 PDF 轉圖檢查直接下載與系統列印版面。直接下載 PDF 為影像式，文字擷取為空；系統列印 PDF 保留可擷取文字。
- 離線重新開啟含圖面及點位照片的案件後，總表與整份報告均可下載 PDF。修正離線轉檔複製畫面未帶入 CSS 的問題，重新轉圖確認表格與標題格式仍在。

資料格式與水準測量計算方法未變更。
