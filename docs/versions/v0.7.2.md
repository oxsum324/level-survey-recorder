# V0.7.2 報告輸出收尾

日期：2026-10-22。基準 main／origin/main `075e4e8ded1b9e2266d9c540b7bcb910c28aa9a8`；分支 `codex/v0.7.2-report-output`。本版僅推送分支並建立 PR，尚未合併或上線。交付 HEAD 與 PR 連結見派工回報。

## 改動

- R1：`pageCanvasPlan` 接受 DOM 保護區間，分頁遇到章節標題及其首區塊、表格列、照片卡或警示時提前結束；重疊區間重新檢查。標題本身另有保護，首區塊過長時仍保留標題保護。量測使用 offsetTop／offsetHeight，避免預覽縮放影響。初始版面關閉 html2pdf 的 CSS 插空分頁，改由本切頁計畫統一處理。每頁短於頁高時使用內層裁切，留下白色頁尾，不把下一頁內容重複印出。
- 超過單頁高度的區塊保留硬切，`oversized` 與 `hardCuts` 記錄可供驗證；不縮字、不縮圖、不降低畫質。多個互相重疊而總長超頁的區間亦可能無法全部保護，切點會列入 `hardCuts`；本次兩個實際案例皆為 0。
- R2：成果總表、完整報告「檢核與計算說明」與 README 計算邊界列出同一段中間視改正方法。計算函式全部不變。
- 版本同步：calc VERSION、sw CACHE、index title／h1、README release URL 為 0.7.2。`calc.js`、`sw.js` 僅版本常數差異；`store.js`、`integrity.js`、`style.css`、vendor、schema、DB_VERSION、備份格式與 CSP 不變；系統列印樣式不動。

## 測試與限制

- 基準 Node 79／79；改後 **84／84**。原斷言保留；新增 4 項分頁案例，涵蓋標題與首區塊、表格列／照片／重疊區間、超長區塊硬切、分數／恰好頁界；另 1 項以實際報告產生函式驗證兩種 HTML 都含指定方法文字。
- `checks/v072-report-browser.js` 透過真實預覽／下載入口驗證；量測與 canvas 記錄見 [pagination.json](assets/v0.7.2-pagination.json)。一般案例為 BM1 起迄、S1 中間視的短測線，2 頁；長案例為 README 三測站算例，另加 S8～S30 中間視與 30 張 800×600 測試照片，33 頁。三站前後視合計仍為 2.825 m、閉合差 0.00 mm；新增中間視不改變閉合差。
- 35 個輸出頁均以 PyMuPDF 渲染為 1.5 倍 PNG，再製作逐頁縮圖拼貼；目視檢查標題、表格列、30 張點位照片與設備參考照片均完整。所有受保護區間跨頁數 0、超長區塊 0、空白頁 0。未宣稱長表跨頁自動重複欄名。
- 所有頁面畫布實測 **1362×2018 px，2,748,516 px²**；scale=2、JPEG quality=0.96，符合邊長≤16,384、面積≤16,777,216。A4、15 mm 邊界不變。
- `checks/v072-method-browser.js` 以成果總表預覽驗證指定字串，PDF 已備妥後擷取文字截圖。瀏覽器 pageerror=0；未完整蒐集 console／網路診斷，不宣稱兩者皆零。
- 使用隔離的 Chromium 案件與 375×812 尺寸；非實體手機驗證。系統列印、手機分享及完整離線回歸本版未重跑，相關程式與樣式未改。
- 曾遇驗證腳本的 VM 不支援 Node 動態 import、beforeunload 使指令提前返回、Python 預設編碼與視窗物件存取問題；改用回傳 JSON、開新分頁載入與 UTF-8。R2 測試初次缺少 DOM remove stub，補齊後通過。未刪除或放寬既有斷言。初測 3 頁一般案例亦有檢查，最終正式證據改採 2 頁短測線。
- 超長單一照片卡／表格列仍可能硬切，是派工明定保留行為；本次已以單元測試覆蓋，未製作超長 DOM 實體 PDF。未完成／待決 U1～U3 延續派工，不自行改計算或 K。
