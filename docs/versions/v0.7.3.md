# V0.7.3 一鍵載入測試案件

## 使用方式

「① 案件與位置」上方按「載入測試案件」。工具先從同站讀取內附 JSON，再顯示既有的備份／取代對話框（即使案件尚無讀數也會提醒）。可先匯出完整案件檔，確認已保存後再取代；取消則保留原案件。成功後直接進入「④ 計算與成果」，可預覽總表或整份報告。

沿用 V0.7.2 的合成測試案件：BM1、S1～S30、TP1／TP2，共 33 個點位；3 個測站、30 張 800×600 編號照片、1 張示意位置圖。資料全部虛構，±5 mm 僅為軟體測試指定值，閉合差 +3.00 mm，不是工程容許門檻。

## 實作界線

- JSON 與程式同站，沿用 connect-src self；不讀取外部站台、不新增 CDN 或執行期套件。
- 測試檔只在點按鈕時下載，約 3.2 MB，首次載入需連網；不列入 Service Worker 啟動預載。
- 共用 importBackup 與 confirmReplacement；原本選檔匯入及建立新案件的確認條件不變。一鍵載入強制顯示備份提醒。
- 下載／解析失敗不取代案件，取消不清除復原資格；成功取代才沿用原流程清除復原。載入中禁用按鈕以防重複請求；網路逾時 30 秒會復原按鈕並提示。重試時清除前次訊息。
- store.js、integrity.js、pdf-pages.js、style.css、schema、DB_VERSION、備份格式與 CSP 不變；calc.js、sw.js 只同步 VERSION／CACHE 為 0.7.3。index title／h1、README release URL 同步。
- 測試資料內容與獨立下載檔相同，SHA-256：e53415002401cdb594700c04a44a8a219e3fb55b0644eb8a5f9f6682729d76a0。

## 驗證

- 基準 85／85；完成 Node 89／89、fail 0。新增測試涵蓋取消保持原案／復原、網路或 HTTP 或解析失敗、備份確認先於取代、成功進入成果頁與重複點擊防護。既有斷言未刪除或放寬。
- 隔離 Chromium 375×812 實際按鈕：模擬失敗、取消取代、匯出後取消備份完成確認、匯出後接受確認均通過。兩個實際下載的原案 JSON 皆保有原案件名稱與 BS 1.234。
- 成功載入 33 點／30 張點位照片與位置圖，閉合差 +3.00 mm；直接顯示計算與成果。報告含 30 張點位照片及 1 張設備參考照，全部圖片解碼成功，34 頁 PDF 可下載與開啟；檢視首末頁。詳細分頁品質沿用同份測試資料與未變更的 PDF 程式。
- 空白案件按鈕也顯示備份對話框，取消後按鈕可再使用。
- 首次瀏覽器檢查的非同步儲存輪詢曾抓到尚未保存的快照；改用持續讀取 IndexedDB 的明確狀態等待後重跑，確認 BS 1.234 在失敗與取消後仍保留。不是放寬斷言；首次結果未當作原始讀數保護通過證據。
- pageerror=0。未全面彙整 console／網路錯誤；故意中斷測試檔請求時的失敗屬預期情境。
- 此為桌面瀏覽器手機尺寸，實體手機仍待使用者測試。備份確認在自動化中以可控制的確認結果執行，不能替代手機確認檔案已存入目標資料夾。
