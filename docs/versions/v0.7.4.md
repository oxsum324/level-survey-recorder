# V0.7.4 測試入口移至頁尾

日期：2026-10-23。基準 main `fe656ad5d70653244c4893b375e5edf83d16d187`；使用者明確選擇 A「將按鈕移到頁尾的測試工具區」。

## 使用方式

「① 案件與位置」捲到最下方 →「測試工具」→「載入測試案件」。按鈕在案件檔匯出／開啟、建立新案件及儲存提醒之後；頁首可直接填寫案件資料。

保留原案備份／取代確認、取消保留原案、載入 30 個觀測點與 30 張照片後直接進入「計算與成果」的流程；首次載入需連網。

## 範圍與驗證

- 僅調整 HTML 入口位置與區塊標題，並同步版本為 0.7.4。app.js、既有測試斷言、資料檔、store.js、integrity.js、pdf-pages.js、style.css 不變；calc.js 與 sw.js 僅改版本常數。schema、DB_VERSION、CSP 及備份格式不變。
- Node 89／89、fail 0，git diff --check 與語法檢查通過。這是位置調整，未新增重複實作的單元測試。
- checks/v074-footer-browser.js：375×812 首屏無測試按鈕、案件欄位在前；testTools 是 routePanel 最後一個區塊；載入按鈕全頁僅一個，無水平溢出。
- 頁尾按鈕可操作，備份對話框出現；取消後原案件名稱保留。確認取代後 33 點、30 張照片與位置圖均讀取成功，直接進入成果頁；總表 PDF 可下載。
- 本次未改分頁程式，完整報告的 34 頁分頁驗證沿用 V0.7.3 同份案件；不將此視為新的實體手機測試。
- 其他複審候選仍屬後續討論，這次依使用者選定範圍交付 A。
