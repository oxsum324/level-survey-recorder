# V0.7.5 複審收尾與手機驗收

日期：2026-10-23。承接 PR #12 的 D1～D6；使用者同意先統一版號，再完成檢查、合併及上線。已發布的 V0.7.4 與當時複審紀錄保留在 v0.7.4.md，本版不改寫該歷史。

## 版本與資料

- index title／h1、calc.js VERSION、sw.js CACHE 及 README 試用網址統一為 0.7.5。
- 只改離線快取版本常數，不改快取策略；新 worker 安裝時重新快取程式。尚未連網的手機不會自動取得新版，既有分頁需重新開啟並確認版號。
- 不清除案件；計算、store.js、integrity.js、schema、DB_VERSION、備份格式、CSP 及第三方程式版本不變。
- 一般網址不顯示測試卡；demo=1 才顯示「案件與位置」頁尾測試工具。首次載入測試案件需連網，測試 JSON 不納入程式預載。
- 測試案件 33 點（BM1、S1～S30、TP1／TP2）、12 張合成照片及位置圖。閉合差 +3 mm、人工容許值 ±5 mm 僅為測試資料，不是工程門檻。

## 手機逐項確認

一般網址：https://oxsum324.github.io/level-survey-recorder/?release=0.7.5

測試網址：https://oxsum324.github.io/level-survey-recorder/?release=0.7.5&demo=1

1. 使用日常同一瀏覽器開一般網址，先匯出完整原案件 JSON，確認檔案已存到手機。不要清除網站資料，也不要以無痕模式作為離線驗收。
2. 連網重開，確認頁首 V0.7.5。若仍是舊版，關閉該工具分頁後重新開啟；暫停測試直到版號正確。
3. 開測試網址，「① 案件與位置」捲到頁尾，按「載入測試案件」。已有讀數／照片時應有備份選項；先按取消，確認原案保留，再載入並確認取代。
4. 確認自動進入「④ 計算與成果」，案件名稱含【測試】、頂列有橘色「測試資料」，照片共 12 張。
5. 按「預覽成果總表」，等待「PDF 已備妥」，逐頁看標題、表頭、首末列與頁尾。按「下載 PDF」，到手機下載資料夾打開檔案；確認與預覽一致，含合成資料警語及 V0.7.5。
6. 關閉預覽，按「預覽整份報告」，下載後逐頁看位置圖、成果表、照片及設備照片。合成照片 01／12～12／12 都應出現，A／B／C／D 四角與 END 完整；設備章節標題與照片應在同頁。
7. 本次 Chromium 手機尺寸參考頁數為總表 2 頁、報告 16 頁。手機差異應記下，不能只以頁數判定通過；重點是無缺頁、空白頁、內容重複或被切斷。
8. 在線上重開一般網址，測試入口應隱藏，已載入案件仍有「測試資料」標籤。確認資料儲存後開飛航模式，關閉 Wi-Fi，重新整理同一網址。確認 V0.7.5、點位、照片仍在，再測總表 PDF 預覽及下載；恢復連網。
9. 如要測讀數復原，只操作測試案件：到「② 觀測讀數」記下某筆讀數，移除後立即復原，確認數字與角色回復。復原前勿重新整理、換案或做其他資料變更，這些操作會清除最近一次復原紀錄。
10. 完成後用「開啟案件檔」匯回第一步備份，確認原案件名稱、讀數及照片。回報手機型號／系統／瀏覽器、步驟編號、實際頁數與異常截圖。

## 已知限制與檢查範圍

- 短末頁僅在併入後不超過頁高且不切保護區塊時合併；否則保留獨立頁，可能有較多空白，不縮字或降畫質。
- 整數 offset 與小數 DOMRect 定位有約 1 px 差異；既有測量中總表最大邊界差 1.168 px，報告兩個切點差 1 px。這是 PDF 版面座標，不是水準測量誤差；不宣稱逐像素相同。
- 新版檢查延用原 99 項 Node 測試及完整既有斷言；checks/release075-browser.js 檢查版號、示範入口與警語、備份／取消、33 點與 12 張照片持久化、兩份 PDF 下載及保護區塊跨頁、離線重開及總表下載。
- 瀏覽器驗證為隔離 Chromium、375×812；實體手機與 Safari 留待使用者測試，不能以桌面模擬代替。
- 本版新增既有函式介面變更：無；執行期第三方行為依賴：無；正式畫面示範入口：僅 demo=1 顯示頁尾卡。
