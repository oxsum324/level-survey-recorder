# V0.7.7 測試案件預填識別欄位

日期：2026-10-24。承接 main e93682ed1a771848ce55c83d78155219b10ee48a（V0.7.6）。

使用者要求測試案件預填戶別、標的物地址與鑑定單位，載入後可直接測試 PDF 頁首，不必手動輸入。

## 改動

- 僅於合成 demo-case.json 加入 householdNo=TEST-A01、address=合成測試路 1 號（非真實地址）、orgName=合成鑑定單位（測試）。其餘案件資料、讀數、33 點及 12 張照片不變。
- 主程式測試資料請求增加 release 版本參數，保留 cache=default，避免讀到上一版本未填三欄的 HTTP 快取。JSON 不加入 Service Worker 預載。
- VERSION、CACHE、HTML title／h1 與 README 網址統一 0.7.7；不改快取策略、計算、資料格式、指紋規則或報告排版。
- 既有測試的路徑斷言同步為含版本參數的精確網址，cache=default 斷言及其餘斷言保留；不新增重複測試。
- 沿用原案件備份／取代對話框、測試標籤及輸出警語。只有載入測試案件才帶測試值，既有案件不會自動變更。

## 操作

開啟 https://oxsum324.github.io/level-survey-recorder/?release=0.7.7&demo=1 →「① 案件與位置」頁尾「載入測試案件」→ 原案先備份並確認取代 → 自動進入成果 → 預覽成果總表／整份報告。三欄已填，可直接下載 PDF 核對首頁。已載入的舊測試案件需重新載入，才會換成新樣本。
