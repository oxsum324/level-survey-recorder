# V0.7.8 案件保存與更正追溯修正

日期：2026-10-25。基準：V0.7.7，632356192c518a441d3ae13c23d216e87439cfc6。

## 使用者可見的修正

- 匯入檔案先驗證元素、點位參照及媒體，再正規化候選案件。無法開啟的檔案不取代原案。合法未完成測線及舊版 schema 1 案件仍可讀取。
- 圖片保存與攝影成果合併納入媒體作業佇列。新建或開啟案件先等待作業完成，再讓使用者決定備份或取代，等待期間暫停案件編輯。切案失敗保留原案，保存失敗可重試。
- 圖片開始匯入時保存所選點位、說明、人員及儀器資料，避免等待後讀到已變更的欄位。
- 三絲帶入既有測線長度時，修改需記錄原因、原值及新值。取消保持原值，相同數值不重複產生更正。
- 接受新觀測或更正時建立穩定觀測識別。同點重測只標記實際更正的那筆，點號更名、角色轉換及復原維持對應。
- 舊更正紀錄只在能唯一對應時套用。無法唯一對應時保留完整操作紀錄並顯示歷史更正核對說明。

## 資料與指紋

格式仍為 level-survey-case.v1，schema 1，IndexedDB 版本 1。既有 pointId 不變。載入或匯入不會自動掃描舊讀數補觀測識別；不改寫原始備份。

指紋演算法不變。未變更的原始舊備份仍可依原內容驗證。實際新增識別、更正或點號更名後，案件內容及指紋會改變，這不是指紋不相容。更名事件保留新舊點號與穩定點位識別。

## 驗證方式

Node 全套包含原有回歸、歷史備份與新增案件安全情境。

```powershell
node --test
```

Chrome 檢查使用真實 IndexedDB、合成資料及本機檔案 request fixtures，停用 Service Worker。檢查壞檔不取代原案、圖片寫入與新建案件交錯、先備份再切案的照片完整性、備份重新匯入、距離更正取消與留痕、同點重測與改名，以及成果總表和完整照片報告 PDF。

瀏覽器腳本預設使用工具箱的 Playwright 安裝位置。其他位置可設定 PLAYWRIGHT_MODULE 為 Playwright index.mjs 的完整路徑。

```powershell
node checks/release078-browser.mjs
```

若執行環境取消原生下載，腳本會記錄 nativeDownloadLimit，並保存應用按下下載時實際產出的 Blob 作為檔案內容驗證。這不算原生下載傳輸通過。此測試也不證明真實 HTTP、離線安裝或實體手機操作。
